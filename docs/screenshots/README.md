## Обновление скриншотов

Запустите FastAPI на порту 8001 и Streamlit на 8501 по инструкции в основном README. Откройте http://localhost:8501. Для аналитики достаточно сохранённого snapshot; для получения рекомендаций нужен работающий API с MovieLens.

Сделайте реальные снимки окна браузера через `Win+Shift+S` и замените соответствующие PNG, сохранив имена и регистр. Включайте заголовки, настройки и читаемые подписи графиков. Не включайте личные данные, посторонние вкладки и панели разработчика.

Для сравнения моделей укажите метрику и K; для alpha сохраните на снимке пояснение о разделении validation/test. Не заменяйте фактическую выдачу макетами или выдуманными результатами. Если имя файла изменится, обновите ссылки в обоих README.
